## Практика 1–2

Реализовать калькулятор математических выражений, содержащих только операции сложения (+) и умножения (*), с веб-формой для ввода и использованием стека.

**Требования:**

- Строка содержит только числа (в обычной нотации, например 1 или 2.02) и операторы +, *.
- Вычисление производится с использованием стека (реализовать отдельным классом).
- Веб-форма: поле ввода, кнопка, вывод результата.
- Валидация ввода: удалять лишние символы или показывать ошибку.

## Структура проекта

- package.json — зависимости и команды npm
- tsconfig.json — настройки компилятора TypeScript
- README.md — описание проекта
- .gitignore — что не попадает в git (например node_modules, dist)

Папка **src/calculator/** — исходники калькулятора:

- index.html — страница: форма ввода и блок вывода
- main.ts — связка страницы с логикой (кнопка, поле, вывод)
- expression.ts — разбор строки, постфикс, вычисление
- stack.ts — класс стека

Папка **dist/calculator/** — скомпилированный JavaScript (появляется после npm run build):

- main.js, expression.js, stack.js

Страница index.html подключает ../../dist/calculator/main.js.

### Установка зависимостей

В корне репозитория выполните:

bash
npm install


### Сборка TypeScript

Команда компилирует файлы из src/ в dist/:

bash
npm run build


Автоматическая пересборка при изменении файлов:

bash
npm run watch


### Запуск в браузере

1. Сначала соберите проект: npm run build (в dist/calculator/ должны появиться .js файлы).
2. Откройте страницу **через локальный сервер** из **корня проекта**. Щелчок по index.html правой кнопкой мыши -> Open with live server
